BLOCKYARD - home-screen app version

1. Upload every file in this folder to one folder on a web host that serves https
   (for example yoursite.com/blockyard/). Keep the file names as they are.
2. On the tablet, open that address once while online.
   iPad:    Safari > Share > Add to Home Screen
   Android: Chrome > menu > Add to Home screen (or Install app)
3. Start it from the new icon. It runs full screen and works offline after that first visit.

Saves belong to the web address. If you played somewhere else first (the single
blockyard.html file, or the Claude page), use "Save to a file / Load a file" on
the start screen to carry players over. On an iPad, load the file after starting
from the home-screen icon, because the icon keeps its own saves, separate from Safari.

To update the game later: replace index.html and change VERSION in sw.js.
